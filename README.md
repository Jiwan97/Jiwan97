## Current Research

### Multidimensional Risk Prioritisation for AWS IAM Principals

My Master's research investigates how AWS IAM principals can be prioritised using multiple dimensions of security risk rather than permissions alone.

The approach considers:

- Permission severity
- Excess permissions relative to expected need
- Resource sensitivity
- Exposure context
- Attack-path potential

The project involves cloud configuration analysis, attack-path modelling and quantitative evaluation of security-risk rankings.
